# Baby Blue Theme

One palette, ported everywhere. Dark and white variants share the same coloring layout:
keywords in baby blue (bold), strings green, comments orange (italic), constants and operators
in a muted grey-green, everything else in the main text color, on one flat background.

`palette.json` is the source of truth: it defines each color **role** for `dark` and `white`.
Every port maps those roles instead of hard-coding hex values.

| Role | Dark | White |
|---|---|---|
| bg | `#181818` | `#ffffff` |
| fg | `#e8e8e8` | `#202020` |
| muted | `#bfc5bf` | `#5b665b` |
| accent (keywords) | `#89CFF0` | `#1677a8` |
| accentFill (buttons) | `#89CFF0` | `#89CFF0` |
| string | `#8ccf59` | `#448219` |
| comment | `#ff9b21` | `#c25e00` |
| link | `#d6b69a` | `#8a6440` |
| selection | `#d38f8f32` | `#d38f8f40` |

White-variant text colors are the dark ones darkened along the same hue, to at least ~4.3:1
contrast on white.

## Ports

| Target | Variants | Source | Installed to |
|---|---|---|---|
| VS Code | Dark + White | `vscode/` (white generated by `vscode/scripts/build-white.mjs`) | Marketplace / `.vsix` |
| Ghostty | Dark + White | `ghostty/themes/` | `~/.config/ghostty/themes/` |
| Neovim (+ lualine) | Dark + White, follows `background` | `nvim/` (hand-written, palette generated) | loaded from this folder by lazy.nvim |
| herdr (CLI) | White (default), Dark, or follow the terminal | `herdr/baby-blue{,-dark,-auto}.toml` | `[theme]` of `~/.config/herdr/config.toml` |
| herdr app | Dark + White, follows appearance | `herdr-app/themes/` | `~/.config/herdr-app/themes/` |
| btop | Dark + White | `btop/themes/` | `~/.config/btop/themes/` |
| Starship | Dark + White palettes | `starship/palettes.toml` | pasted into `~/.config/starship.toml` |
| ls / eza / fd / zsh completion | Follows the terminal (ANSI slots only) | `shell/ls-colors.zsh` | sourced from `~/.zshrc` |

Terminal ports use the same 16 ANSI colors as the VS Code integrated terminal, with no yellow:
ANSI yellow and bright yellow are baby blue.

### Rebuild after changing the palette

```sh
node scripts/build.mjs          # Ghostty, btop, herdr, Starship, Neovim palette
(cd vscode && npm run build:white)
./install.sh                    # copy theme files into ~/.config
```

### Default: white

White is the default everywhere outside VS Code. To switch a port to dark:

- Ghostty: `theme = Baby Blue`, or follow macOS with `theme = light:Baby Blue White,dark:Baby Blue`
- Neovim follows Ghostty on its own
- herdr (CLI): `HERDR_THEME=dark ./install.sh` (or `HERDR_THEME=auto` to follow the terminal), then `herdr server reload-config`
- herdr app: `"appearance": "dark"` in `settings.json` (remove the key to follow macOS)
- btop: `color_theme = "baby-blue"` in `btop.conf`
- Starship: `palette = "baby_blue"` in `starship.toml`

## VS Code

The dark theme is hand-made. The white theme is generated from it, so edit the dark one
(or `palette.json`) and rebuild:

```sh
cd vscode
npm run build:white
npx @vscode/vsce package
```
